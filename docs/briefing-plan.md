# 巡巡每日简报实施与测试计划

## 实施顺序

1. 接入公开数据。用 Open-Meteo 查城市与预报，用 GitHub REST 查询 Claude Code、Codex 正式版和主题仓库，用 OpenAI、Google DeepMind、Hugging Face 官方订阅源获取文章。接口独立超时，成功结果单独缓存。
2. 组装每日简报。天气展示城市、当地预报日期、温度范围和 07:00–10:00 逐小时降水概率的最高值。GitHub 项目取近 7 个 UTC 日创建、按累计星标排序的前三个，显示所用主题。资讯按所选关键词、发布时间和原文链接筛选，每次最多显示 3 条。
3. 接入 Windows 桌面。托盘和巡巡右键都能打开简报、手动刷新和设置。联网简报默认关闭，城市手动搜索选择。启用后按本地时间每天最多弹出一次，开机或解锁后只补发当天；任务气泡、喝水或起身提醒与免打扰优先。编写叼报纸和撑伞的短动作。气泡自动收起后可回托盘查看。
4. 加入可选任务小结。每日指定时间统计任务收件箱当天保留的完成记录及当前待审批、待回答数量，打开收件箱处理。小结单独开关，在本地运行。
5. 自测、真实接口冒烟、Windows 界面回归、打包。发布包包含已测试的单文件 EXE。构建与测试输出保存在 Git 忽略的目录中。

默认简报时间为 08:30，小结为 18:00。一个刷新周期只抓取启用栏目，城市未选时跳过天气。自动刷新每本地日尝试一次，失败后可手动刷新。第一次看到工具正式版时建立基线，后续版本变化才计入更新提醒。查看详情时仍可看到每个工具当前最新的正式版。

## 测试矩阵

| 编号 | 层级 | 场景与操作 | 通过判据 |
| --- | --- | --- | --- |
| B01 | 离线 | 恢复旧版空配置、损坏 JSON 与缺字段配置 | 启用状态、时间和筛选值采用有效默认值，联网简报默认关闭 |
| B02 | 离线 | 城市同名、缺少坐标或越界坐标；预报有空小时值 | 匹配项显示地区供用户选择；无效项被排除；缺测保留为暂缺，预报日期和有效时段数据准确 |
| B03 | 离线 | GitHub 正式版初次读取、再次读取及版本变化 | 首次建立基线，同版本无更新，新正式版产生一条；预发行、草稿及非预期链接不入简报 |
| B04 | 离线 | GitHub 候选含重复仓库、空榜单和不完整搜索 | 最多 3 个合法条目，顺序符合累计星标，高亮口径展示主题与时间窗。不完整结果走失败分支 |
| B05 | 离线 | RSS、Atom、重复链接、无日期、旧文和关键词 | 只选新近且匹配的有效文章，去重后最多 3 条。XML 外部实体被拒绝 |
| B06 | 离线 | 部分来源返回 429、超时、异常 JSON，完整预报返回 503 | 成功栏目保留。完整预报可降级到日预报，上午降水概率标记暂缺。其余失败栏目沿用匹配缓存并标记更新时间；无缓存显示暂不可用 |
| B07 | 离线 | 调整城市和主题后读取旧缓存 | 筛选参数改变时仅显示匹配新配置的数据；旧城市或主题结果不会出现在新栏目 |
| B08 | 离线 | 到点前、到点后、跨天、同日重启及同日消息去重 | 日程按本地日期生效，两个日程分别最多一次。当日补发有内容的一份；下次重启不再重复 |
| B09 | 离线 | 同时存在当天完成、之前完成、待审批、待回答 | 按本地日统计当天保留的完成记录，待处理数反映收件箱当前状态 |
| B10 | 离线 | 不安全 URL、超大响应、取消及重复刷新 | 链接限 HTTPS 和对应来源站点，单源限制响应大小，取消不更新缓存，重复点击不会并发发出同一批请求 |
| B11 | 实际接口 | 本机查询一个测试城市与逐小时天气，并抓取启用的公开 GitHub 和资讯源 | 城市、日期、温度可读，正式版和 GitHub 三项查询成功。记录每个真实接口的结果，失败源按降级场景记录 |
| B12 | Windows 界面 | 托盘打开简报，配置时间、栏目、主题和城市，关闭后重新打开 | 选项保存，刷新期间窗口仍可响应，栏目内容、更新时间和失败状态可见 |
| B13 | Windows 界面 | 模拟到点、任务审批抢占、免打扰及桌面空闲 | 优先级符合预期，简报只在可显示时弹出。气泡收起后仍可查看详情，动作会结束并恢复漫游 |
| B14 | Windows 界面 | 本地小结到点并点开收件箱 | 计数符合已接收的本地记录，点击入口可打开任务收件箱 |
| B15 | 回归与打包 | 运行内置自测，发布 win-x64 单文件，校验 ZIP 和部署的 EXE | Hook、T3、终端跳转、双屏、喝水提醒和任务收件箱无回归；ZIP 仅含 EXE，与被测文件哈希相同；新版可正常启动 |

锁屏调度用可控状态测试，不锁定当前用户的桌面。真实接口冒烟只读取公开数据，不提交任务或调用大模型。
